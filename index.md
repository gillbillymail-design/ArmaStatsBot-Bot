# ArmaStatsBot-Bot
ArmaStatsBot Privacy Policy

Last Updated: August 2026
Owner: GillBillyzz (Developer of ArmaStatsBot)

1. Introduction
ArmaStatsBot is a Discord bot that connects Arma Reforger game servers to Discord.
It receives gameplay data from the user’s Arma server and provides features such as killfeed, match statistics, global leaderboards, and player‑linked stat commands.

This Privacy Policy explains what data the bot collects, how it is used, and how users can request removal of their data.

2. Data We Collect
ArmaStatsBot collects only the minimum data required to operate its features.

2.1 Discord Data
The bot may store the following Discord data:

- Discord User ID  
Used to link a Discord user to their Arma player UID so the bot can show correct stats.

The bot does NOT collect:
- Discord usernames
- Nicknames
- Avatars
- Messages
- Message content
- Presence/activity
- Server member lists
- DMs
- Email addresses
- Any personal information

2.2 Arma Server Data
The bot stores gameplay data sent from the user’s Arma Reforger server, including:
- Player UID
- Player name (as provided by the game server)
- Kills, deaths, suicides, teamkills
- Bases captured
- Supplies delivered
- Supply points
- Hours played
- Match snapshots
- Live player lists
- Global statistics
This data comes only from the user’s Arma server and is not collected from Discord.

3. How We Use the Data
The data is used exclusively for bot functionality:
- Linking Discord users to their Arma player profile
- Displaying player statistics
- Generating leaderboards
- Showing killfeed and match updates
- Managing per‑server configuration
- Verifying admin permissions for setup commands
The bot does not use data for advertising, analytics, profiling, or any external purpose.

4. Data Storage
All data is stored locally on the bot’s server in JSON files.
- We do not use external databases.
- We do not share data with third parties.
- We do not sell or transfer user data.

5. Data Sharing
ArmaStatsBot does not share any data with:
- Third‑party companies
- Advertisers
- Analytics services
- Other Discord bots
- External APIs
-The only data shown publicly is gameplay statistics that the user’s Arma server already exposes.

6. Data Removal Requests
Users may request removal of their stored Discord ID or Arma player data at any time.
To request deletion:
- Contact the bot developer (GillBillyzz)
- Provide your Discord User ID
- Request removal of your linked data
- Your data will be removed from all bot storage within 72 hours.

7. Children’s Privacy
ArmaStatsBot does not knowingly collect data from children under 13.
The bot only stores Discord IDs and gameplay stats, and does not collect personal information.

8. Changes to This Policy
This Privacy Policy may be updated as needed.
The “Last Updated” date will always reflect the most recent revision.
